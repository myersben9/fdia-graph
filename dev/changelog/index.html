    Changelog¶

    Every release lists what a user of the package can see change. "No user-visible change" means the public API, the generated files and the numbers are the same as the previous release.

    Unreleased¶

    • The false state of a goal has one entry point, in FalseState (no change in behaviour). goal_state moves from Minimizer to FalseState (g.false_state.goal_state), with load_goal_state and flow_goal_state beside it. The load goal's solve was written twice (once for the ramp's frames, once for the search) and is now written once. So the search's window no longer calls back into the search, and an overload frame no longer goes through it. Leftover parameters are gone: RampFrames.attack_frame(x_true, family, design, knobs) is ramp_frame(x_true, design, knobs) (the family could only be At), and EpisodeDesigns.am_overload_design(X, t, length, knobs, rng) is am_overload_design(states, knobs, rng) (it was only ever given a whole window). Every IEEE timeline is byte for byte what it was.

    • One word for each set of buses in the attack code (no change in behaviour). The code used about eight words for four things. Now: the area is where the attacker may act, the support is the set of buses a false state re-solves, the boundary is the buses one branch outside it, and the reach is the support with its boundary. The glossary defines each.

The attacks page and the glossary are corrected where they said something the code does not do: a ramp's targets need not be neighbours; a ramp stays one step away from the true load after its return and can end before the return is complete; the search tries the whole area first; a ramp checks the generator limits inside the buses it re-solves and not on the buses one branch outside, where an overload does; the third rating source "delta"; the tamper threshold is the rated accuracy for At and the paper noise for Am; the designs are methods of EpisodeDesigns; and a search that finds no support records -1 devices and the ramp runs on its whole area.

    • One file layout. A timeline has flows at the from end of a branch and PMU currents as real and imaginary part, on every test system; nothing in the package wrote any other form since the New York source left, so the other form is gone from the package.

    • Removed: LayerSet (both_ends, temporal) and the spec argument of FdiaGenerator and TimelineWriter; MeterKind.I and IA, PolarCurrentChannel, EdgeChannel.P_TO and Q_TO; schema.CURRENT_POLAR; Capability.RECTANGULAR_CURRENTS; FdiaGraph.current_form.     • A file that declares another layout (four flows in edge_feat, or a current_form other than rectangular) is refused with NotATimeline when it is opened (models.inputs.ReadableLayout), where before an estimator refused a polar file at the fit. Every released file opens as before.
    • The notes file that sat inside the package is deleted; the rules it restated are in CONTRIBUTING.md and the tests.

    • Every IEEE timeline is byte for byte what it was.

    • The two densest files of the attack core are split by job. No method's logic changed, and every IEEE timeline is byte for byte what it was.

    • engine/attacks/frames.py, the new part AttackFrames (g.attack_frames): frame_from_state, frame_from_vector, attack_vector, current_attack, currents_with_attack and changed_meters, out of false_state.py, which keeps the solves and the limits.

    With the onset survey on, a waiting family is placed only at onsets whose design the survey already holds, so it never moves; the rule then acts on the families that start anywhere (the ramp). A verbose New York build no longer prints a line per stretch written or per fifty designs; the survey still reports its progress. The survey cache keeps its _v2 chunks.

    What changes in a New York dataset: every noisy reading (data/node_x, data/edge_x, data/pmu_i and their benign/ twins) is a new draw of the same noise model, and through the rounding of the benign scan the attack z - z_benign moves in its last float32 digit. Where every placed design finds an attack (the three stored digests) nothing else moves: the true state (clean/), the splits, the placed and designed episodes, the labels, the tamper masks and every attribute are the same. Where a design fails, the timeline now holds an episode at another onset in place of benign frames, so it carries more attacked frames, closer to attacked_frac, and its episode_redraws attribute is no longer always zero. No New York dataset is released, so no published number changes.
